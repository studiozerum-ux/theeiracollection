# The Eira Collection

> *A selective guide to Europe and the world's most compelling kitchens, dining rooms, and secluded sanctuaries. Selective by design, and kept deliberately small.*

---

## ✦ Overview
**The Eira Collection** is an architectural, delicate digital luxury web application inspired by the digital minimalism and editorial authority of platforms like [ouichefguide.com](https://www.ouichefguide.com) and [gastrognito.com](https://gastrognito.com).

Built with **Next.js 15 (App Router)**, **TypeScript**, and **Tailwind CSS**, it features:
- **Warm Alabaster Canvas & Delicate Contrast:** A tactile, soft palette (`#FCFCFA` alabaster, `#F7F5F0` sand, `#0A0D11` obsidian, and antique champagne gold accents).
- **Cinematic Hero:** Real-time crossfading visual scenes with floating metadata tags and curated highlights.
- **Eira Cinema & Film Atelier (`/cinema` & homepage showcase):** A dedicated section offering high-end 4K cinema direction, sensory vignettes, and documentary filmmaking tailored for world-class Michelin kitchens and Relais & Châteaux retreats.
- **Asymmetrical Curation Grid ("This Week on the Pass"):** Dynamic cards with circular navigation accents.
- **The Signature Hover-List:** Instantaneous image preview swapping on hover across all featured dining rooms.
- **Interactive Directory & Map (`/explore`):** Multi-dimensional filtering by country (Norway, Denmark, Sweden, France, Switzerland, Japan) and type (Restaurants vs. Stays).
- **Dedicated Experience Profiles (`/experiences/[slug]`):** Static Site Generated (SSG) detail views featuring an editorial dossier, chef & sommelier credits, direct reservation links, and high-resolution galleries.
- **Magazine & Journal (`/magazine`):** Long-form essays exploring regional terroir, architectural hospitality, and gastronomic philosophy.
- **Global Search Modal:** Quick keyboard-driven (`⌘K` / `Ctrl+K`) search across all venues, cinema reels, and destinations.
- **Apply for Inclusion (`/get-listed`):** Dedicated gateway for hoteliers and restaurateurs to submit properties for editorial review.

## ✦ Tech Stack
* **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
* **Language:** TypeScript
* **Styling:** Tailwind CSS with custom delicate editorial configuration
* **Icons:** Lucide React
* **Typography:** *Instrument Serif* (Display) & *Plus Jakarta Sans* (Interface)

## ✦ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```

## ✦ 1-Click Deployment to Vercel
This repository is pre-configured for instant zero-configuration deployment on **Vercel**:
1. Go to [Vercel](https://vercel.com) and click **Add New Project**.
2. Select the repository `studiozerum-ux/theeiracollection`.
3. Click **Deploy**. Your site will be live on an edge network with automatic SSL.
