# The Eira Collection

> *A selective guide to Europe and the world's most compelling kitchens, dining rooms, and secluded sanctuaries. Selective by design, and kept deliberately small.*

---

## ✦ Overview
**The Eira Collection** is an architectural, high-contrast digital luxury web application inspired by the digital minimalism and editorial authority of platforms like [ouichefguide.com](https://www.ouichefguide.com) and [gastrognito.com](https://gastrognito.com).

Built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**, it features:
- **Cinematic Hero:** Real-time crossfading visual scenes with floating metadata tags and curated highlights.
- **Asymmetrical Curation Grid ("This Week on the Pass"):** Dynamic cards with circular navigation accents.
- **The Signature Hover-List:** Instantaneous image preview swapping on hover across all featured dining rooms.
- **Interactive Directory & Map:** Multi-dimensional filtering by country (Norway, Denmark, Sweden, France, Switzerland, Japan) and type (Restaurants vs. Stays).
- **Dedicated Experience Profiles (`/experiences/[slug]`):** Static Site Generated (SSG) detail views featuring an editorial dossier, chef & sommelier credits, direct reservation links, and high-resolution galleries.
- **Magazine & Journal:** Long-form essays exploring regional terroir, architectural hospitality, and gastronomic philosophy.
- **Global Search Modal:** Quick keyboard-driven (`⌘K` / `Ctrl+K`) search across all venues and destinations.
- **Apply for Inclusion:** Dedicated gateway for hoteliers and restaurateurs to submit properties for editorial review.

## ✦ Tech Stack
* **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
* **Language:** TypeScript
* **Styling:** Tailwind CSS with custom editorial configuration
* **Icons:** Lucide React
* **Typography:** *Instrument Serif* (Display) & *Plus Jakarta Sans* (Interface)

## ✦ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```

## ✦ 1-Click Deployment to Vercel
This repository is pre-configured for instant zero-configuration deployment on **Vercel**:
1. Go to [Vercel](https://vercel.com) and click **Add New Project**.
2. Select the repository `studiozerum-ux/theeiracollection`.
3. Click **Deploy**. Your site will be live on an edge network with automatic SSL.
